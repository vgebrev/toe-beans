# Brand assets (placeholder)

The paw print here is the **placeholder** mark from the mock-ups: one main pad and four toe beans
on a 64-unit grid. S0.9's AI-assisted logo replaces it (`ui.md` §6.4 Logo). When it lands,
redraw these files from it and update `Logo.svelte`, which inlines the same shapes.

| File | Use |
|---|---|
| `mark.svg` | The mark alone, in brand brown |
| `favicon.svg` | Browser tab icon: brown paw, tan in dark mode |
| `maskable.svg` | Source for the maskable app icon: paw inside the 80% safe zone on a solid background |
| `badge.svg` | Source for Android's notification badge: white silhouette on transparent |

The PNG sizes the manifest and push need (192, 512, maskable 512, badge 96) are exported from
these in S13.1, with the manifest.
